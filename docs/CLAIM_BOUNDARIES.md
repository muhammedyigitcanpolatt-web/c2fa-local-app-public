# Claim Boundaries

## Safe Boundary

C2FA Local verifies file-level integrity evidence and available C2PA-related metadata. It does not prove that media content is true or authentic.

## What The App Does Not Claim

- production readiness
- public release readiness
- full C2PA coverage
- truth
- authenticity
- forensic proof
- certification

## Allowed Language

- local-first
- experimental
- source preview
- evidence
- validator-backed status
- local JSON export

## Dangerous Language To Avoid

- proves media is real
- guarantees authenticity
- fully verifies C2PA
- production ready
- public release ready
- certified
- forensic proof
- tamper-proof
